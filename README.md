# Event Project

Starter structure for a PHP event registration project.

## Project structure

- `.github/workflows/php-check.yml` runs PHP syntax checks on pushes and pull requests.
- `admin/` is reserved for administration pages.
- `assets/css/` and `assets/js/` are reserved for front-end styles and scripts.
- `config/` is reserved for application configuration.
- `includes/` is reserved for shared PHP components.
- `database.sql` is reserved for the database schema and seed data.

The registration form, submission handling, and database integration are placeholders and still need to be implemented.

## Local setup

1. Place the project in your PHP web server's document root.
2. Start Apache and MySQL if using XAMPP.
3. Open `http://localhost/event_project/`.
